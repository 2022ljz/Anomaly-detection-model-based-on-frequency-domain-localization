1.请在python3.9环境中使用项目的requirements.txt进行环境配置：
pip install -r requirements.txt

2.然后请安装2.5版本的gpu-pytorch（可以直接去官网安装）：

# 实例CUDA=12.1，请根据自己设备的CUDA版本安装。
pip install torch==2.5.0 torchvision==0.20.0 torchaudio==2.5.0 --index-url https://download.pytorch.org/whl/cu121

3.通过如下命令行运行脚本进行实验：
$ sh scripts/MSL.sh 
$ sh scripts/SMAP.sh 


注意：本项目已经在checkpoints文件夹下提前训练好了一组模型，想要直接看异常检测效果，请在scripts文件夹下将对应的脚本文件中训练部分（第一行）的num_epochs参数设置为0，再去运行脚本文件。这样，会直接调用训练好的模型在数据集上进行异常检测并输出结果。
